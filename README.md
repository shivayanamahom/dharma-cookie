## Что это

Системный плагин Joomla `plg_system_dharmacookie`, который показывает посетителю небольшое окно:

> **Мы используем куки и рекомендательные технологии**
> Это помогает сайту работать лучше.
> Продолжая пользоваться сайтом, вы соглашаетесь на использование [файлов cookie].
> **[ Понятно → ]**

Посетитель нажимает кнопку, браузер запоминает это, окно больше не появляется. Если вы обновите политику, достаточно поменять «версию политики» — окно покажется всем заново.

Это **простое уведомление**, а не менеджер согласий: без категорий, без блокировки сторонних скриптов, без журнала. Именно так сделано у большинства крупных российских магазинов.

## Возможности

- 🪶 **Очень лёгкий.** Без jQuery и Bootstrap, без базы данных, без лишних запросов. CSS и JS (около 4 КБ) выводятся прямо в `<head>`.
- ⚡ **Дружит с кэшем.** Окно строится в браузере из маленького JSON-конфига, HTML страницы не зависит от куки.
- 🎨 **Подстраивается под шаблон.** Шрифт наследуется от сайта, цвет кнопки берётся из `--dharma-primary`. Три положения (карточка слева, карточка справа, панель внизу) и две темы.
- 🔘 **Кнопка как у вашего шаблона.** Можно задать свои CSS-классы кнопки и значка (например, `knopka ripple-hover` и `ar-arrow`).
- ✍️ **Простые тексты.** Каждая строка — абзац, слова в `[квадратных скобках]` — ссылки.
- 🌍 **ru-RU и en-GB.** Если поле текста пустое, берётся текст по умолчанию на языке сайта.
- ♿ **Доступность.** `role="dialog"`, управление с клавиатуры, учёт `prefers-reduced-motion`, скрыто при печати.
- 🧪 **Тестовый режим.** Окно показывается при каждой загрузке, пока вы настраиваете внешний вид.

## Установка

1. Скачайте [`plg_system_dharmacookie.zip`](https://github.com/shivayanamahom/dharma-cookie/releases/latest/download/plg_system_dharmacookie.zip) со страницы релизов.
2. В админке Joomla: **Система → Установка → Расширения** и загрузите zip.
3. **Система → Плагины**, найдите **«Система — Dharma Cookie»** и включите.
4. Откройте плагин, на вкладке «Тексты» укажите адреса ссылок на вашу политику.

> Требуется Joomla 5 или 6. Плагин проверен на Joomla 6.2 и PHP 8.4.

## Настройки

### Вкладка «Плагин»

| Поле | Что делает |
|---|---|
| Тестовый режим | Окно показывается при каждой загрузке, кука согласия не проверяется. На рабочем сайте выключите. |
| Версия политики | Хранится в куке. Измените значение (`1` → `2`), и окно снова появится у всех. |
| Срок хранения согласия | Сколько дней браузер помнит нажатие (1–730, по умолчанию 365). |

### Вкладка «Тексты»

| Поле | Что делает |
|---|---|
| Заголовок | Жирная строка сверху. |
| Текст | Каждая новая строка — новый абзац. Слова в `[квадратных скобках]` станут ссылками. |
| Адрес первой ссылки | Куда ведёт первое слово в скобках. |
| Адрес второй ссылки | Куда ведёт второе слово в скобках. |
| Текст кнопки | Подпись на кнопке. |

Пример текста:

```text
Это помогает сайту работать лучше.
Продолжая пользоваться сайтом, вы соглашаетесь на использование [файлов cookie].
Подробнее о [рекомендательных технологиях].
```

С адресами `/politika-cookie` и `/rekomendatelnye-tehnologii` оба выделенных выражения станут ссылками. Если адрес не указан, слово выводится обычным текстом (скобки убираются).

Адрес — это путь от корня сайта (`/politika`) или полный `https://…`. Адреса других видов (`javascript:`, с пробелами, с обратным слэшем) плагин отбрасывает.

### Вкладка «Внешний вид»

| Поле | Что делает |
|---|---|
| Положение | Карточка внизу слева (по умолчанию), внизу справа или панель внизу по ширине контейнера. |
| Тема | Тёмная (по умолчанию) или светлая. |
| Класс кнопки | Свои CSS-классы кнопки через пробел. Если заполнено, собственный вид кнопки плагина отключается и работает только ваш класс. |
| Класс значка в кнопке | Добавляет в конец кнопки пустой `<span>` с этим классом (например, `ar-arrow` для стрелки). |
| Свой CSS | Дополнительные правила. |

### Оформление через CSS

```css
.dck {
    --dck-bg: #0a0a0a;   /* фон окна */
    --dck-fg: #ffffff;   /* цвет текста */
}
.dck__ok {
    background: var(--dharma-primary, #2f5bff); /* кнопка по умолчанию */
}
```

Классы: `.dck` (окно), `.dck__t` (заголовок), `.dck__p` (абзац), `.dck__b` (кнопка), `.dck__ok` (собственный вид кнопки, если не задан «Класс кнопки»).

## Повторный показ и JavaScript

- Любая ссылка или кнопка с атрибутом `data-cookie-settings` снова показывает окно (удобно для подвала):

  ```html
  <a href="#" data-cookie-settings>Настройки cookie</a>
  ```

- `DharmaCookie.show()` показывает окно, `DharmaCookie.accepted()` возвращает `true`, если посетитель уже согласился с текущей версией политики.
- Когда посетитель нажимает кнопку, на `document` срабатывает событие `dharmacookie:accept`.

## Как хранится согласие

| | |
|---|---|
| Имя куки | `dharma_cookie` |
| Значение | версия политики из настроек |
| Срок | как в настройке «Срок хранения согласия» |
| Область | корень сайта Joomla, `SameSite=Lax`, `Secure` на https |
| Кем ставится | браузером из JavaScript (не `HttpOnly`) |

Персональные данные не собираются и никуда не отправляются: плагин не делает сетевых запросов и не пишет в базу.

## Безопасность

Перед релизом плагин проверен на вредоносные значения настроек (`<img onerror>`, `</script>`, `</style>`, `javascript:`, адреса с табуляцией и обратным слэшем, кавычки в классах). Итог:

- Тексты в окно попадают через `textContent`, а не `innerHTML`.
- Конфиг передаётся в JS как JSON с экранированием `<`, `>`, `&` и кавычек, из `<script>` выйти нельзя.
- Адреса ссылок: разрешены `http(s)://`, `//…` и пути от корня; всё остальное отбрасывается.
- Классы кнопки и значка: только буквы, цифры, дефис, подчёркивание и пробел.
- «Свой CSS» очищается от `<`, чтобы нельзя было закрыть тег `<style>`.
- Плагин не читает данные посетителей, не использует базу и не делает запросов к другим серверам.

Настройки плагина и «Свой CSS» редактируют только администраторы Joomla. Если на сайте включён строгий CSP без `'unsafe-inline'`, проверьте, что inline-стиль и скрипт плагина не блокируются.

О найденной проблеме пишите в [Issues](https://github.com/shivayanamahom/dharma-cookie/issues).

## Чего плагин не делает

- Не блокирует сторонние скрипты (Метрика, Google Analytics и т. п.) до согласия.
- Не делит куки на категории и не даёт отказаться.
- Не ведёт журнал согласий.

Это не юридическая консультация. Тексты, политику и обработку персональных данных для вашего сайта согласуйте с юристом.

## Структура

```text
dharmacookie.xml                манифест и настройки
services/provider.php           регистрация плагина
src/Extension/DharmaCookie.php  логика (около 150 строк)
assets/banner.css               оформление
assets/banner.js                показ окна и сохранение согласия
language/{ru-RU,en-GB}/         тексты интерфейса и значения по умолчанию
```

Сборка zip: содержимое репозитория без `README.md` и `.gitignore`, файл `dharmacookie.xml` должен лежать в корне архива.
